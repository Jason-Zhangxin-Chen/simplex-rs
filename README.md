# Simplex-rs
It is a rust implementation of BFT consensus Simplex. For details please refer to the papers:
- raw paper
  https://eprint.iacr.org/2023/463.pdf
- and its improvement
  https://eprint.iacr.org/2023/1916.pdf
I am trying to build a common crate of it that abstract the unerlying blockchain and network layer, focus on the internval protocol of the algorithm. Thus that it can be reused in differenct system.
